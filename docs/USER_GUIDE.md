# Guía de Usuario

Bienvenido a **Maestros**, la aplicación que conecta profesionales de servicios del hogar con clientes.

## Para Clientes

### Encontrar un Profesional
1.  **Pantalla de Inicio**: Navega entre los profesionales recomendados.
2.  **Filtrar**: Toca la barra de ubicación en la parte superior para filtrar por Región y Comuna.
    *   *Consejo*: Usa "Usar mi ubicación actual" para detectar tu área automáticamente.
3.  **Buscar**: Usa la barra de búsqueda para encontrar oficios específicos (ej. "Gasfiter").

### Reservar un Servicio
1.  Toca la tarjeta de un Profesional para ver su perfil.
2.  Haz clic en **"Reservar ahora"**.
3.  Completa los detalles:
    *   **Descripción del Problema**: Sé específico.
    *   **Emergencia**: Marca esta casilla si necesitas ayuda inmediata (deshabilita la agenda).
    *   **Fecha/Hora**: Selecciona si no es una emergencia.
    *   **Dirección/Teléfono**: Confirma tu información de contacto.
4.  Toca **"Solicitar cotización"**.

### Gestionar Reservas
1.  Ve a la pestaña **"Mis Reservas"**.
2.  Revisa el estado: `Pendiente`, `Confirmado`, etc.
3.  **Calificar**: Una vez completado el trabajo, toca "Calificar" para dejar estrellas y una reseña.

---

## Para Profesionales

### Tu Perfil
1.  **Panel (Dashboard)**: Mira tus estadísticas diarias.
2.  **Cambiar Estado Online**: Mueve el interruptor en la parte superior para aparecer visible/oculto en las búsquedas.
    *   *Nota*: La app te pone "Online" automáticamente al abrirla y "Offline" al cerrarla.
3.  **Editar Perfil**: Ve a la pestaña "Perfil" -> "Editar Datos Personales" para actualizar tu foto, descripción o precio.

### Gestionar Solicitudes
1.  **Panel**: Las nuevas solicitudes aparecen en "Nuevas Solicitudes".
2.  **Revisar**: Mira los detalles, distancia y nombre del cliente.
3.  **Acción**:
    *   **Aceptar**: Confirma el trabajo.
    *   **Rechazar**: Declina la solicitud.
4.  **WhatsApp**: En la pestaña "Agenda", toca el ícono de WhatsApp para chatear directamente con el cliente.
